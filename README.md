# Bu Gece

Bu Gece — ilgi odaları + gece planı.

## Proje Hakkında
Bu proje, kullanıcıların ilgi alanlarına göre farklı odalar ve gece planları oluşturmasına yardımcı olacak bir deneyim sunar.

## Özellikler
- İlgi odaları teması
- Gece planı oluşturma
- Kullanıcı odaklı deneyim
- Genişletilebilir yapı

## Başlangıç
Projeyi çalıştırmak için bu depoyu klonlayın:

```bash
git clone https://github.com/delibaltabaris5-hash/bu-gece.git
cd bu-gece
```

Daha sonra proje gereksinimlerine göre gerekli kurulum adımlarını uygulayın.
